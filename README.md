# CAFSDryChain

Proposed System Workflow

## Step 1: Produce Registration
When a farmer or supplier brings produce to the solar-powered dryer, an authorized operator registers the batch through the web application by entering details such as:
- Product type
- Source (farm or market)
- Farmer/Supplier information
- Fresh weight
- Date of delivery

The system generates a unique Batch ID and QR code for the produce, while creating a secure blockchain record for future verification.

## Step 2: Drying Process
As the drying process progresses, the dryer operator updates the batch information through the web application by recording:
- Drying start time
- Drying completion time
- Final weight
- Moisture level
- Quality observations

Each update is securely recorded, creating a transparent and tamper-resistant history of the drying process.

## Step 3: Storage & Distribution
Once drying is completed, the system records:
- Storage location
- Packaging details
- Transportation information
- Destination or buyer

This ensures every movement of the product is traceable from production to delivery.

## Step 4: Product Verification
Each package carries its unique QR code. When scanned by regulators, buyers, or consumers, the system displays the complete history of the product, including:
- Product type
- Source
- Drying records
- Storage information
- Distribution history
- Verification status

This allows stakeholders to instantly verify the authenticity and traceability of the product.

## Step 5: Monitoring & Reporting
Project administrators access a centralized dashboard to:
- Monitor all registered batches
- Track drying activities across locations
- Generate reports
- Verify blockchain records
- Audit the complete product lifecycle
